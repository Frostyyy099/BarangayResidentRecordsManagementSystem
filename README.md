# Barangay Resident Records Management System

## Project Description

The Barangay Resident Records Management System (BRRMS)
is a proposed system designed to help barangay staff
organize and manage resident records more easily.

The system aims to make searching, viewing, and updating
resident information faster and more organized.

## Organization

Barangay Office

## Location

General Santos City, Philippines

## System Category

Transaction Processing System (TPS)

## Technologies Used

- HTML
- CSS
- JavaScript

## Main Features

- Resident Records Management
- Search Resident Records
- Update Resident Information
- View Resident Records
- Dashboard Interface
